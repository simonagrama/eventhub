# EventHub 🎫

EventHub este un proiect personal pentru gestionarea și descoperirea evenimentelor. Proiectul include o versiune web realizată cu HTML, CSS și JavaScript, precum și o aplicație mobilă realizată cu React Native și Expo.

## 🌐 Website

Versiunea web permite utilizatorilor să:

* vizualizeze evenimentele disponibile
* caute evenimente
* filtreze evenimentele după categorie
* vadă detaliile unui eveniment
* adauge evenimente noi
* editeze evenimente existente
* șteargă evenimente
* selecteze data evenimentului
* adauge o descriere și un preț
* păstreze evenimentele salvate folosind `localStorage`

### Tehnologii

* HTML5
* CSS3
* JavaScript
* LocalStorage

## ⚛️ React

Versiunea React a proiectului urmărește aceeași idee de gestionare a evenimentelor, dar folosește componente React și state management.

Funcționalități:

* adăugare evenimente
* editare evenimente
* ștergere evenimente
* validarea formularului
* filtrarea și afișarea evenimentelor
* gestionarea stării cu React Hooks
* salvarea datelor

### Tehnologii

* React
* JavaScript / TypeScript
* React Hooks

## 📱 React Native

Pentru partea mobilă am creat o aplicație folosind React Native și Expo.

Aplicația permite:

* adăugarea evenimentelor
* editarea evenimentelor
* ștergerea evenimentelor
* selectarea categoriei cu un selector
* selectarea datei folosind un calendar
* adăugarea unei descrieri
* validarea datelor introduse
* vizualizarea detaliilor evenimentului
* păstrarea datelor după repornirea aplicației

Pentru persistența datelor am folosit `AsyncStorage`.

### Tehnologii

* React Native
* Expo
* TypeScript
* AsyncStorage
* React Native Picker
* React Native DateTimePicker
